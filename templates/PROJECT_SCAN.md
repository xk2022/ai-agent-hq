## 安全與執行前檢查

- 不修改受管理專案的已追蹤檔案，不建立 Commit，不推送、不部署。
- 不接觸正式憑證，不保存 API Token，不將私人資料放入公開 Repository。
- 高風險操作須先由 Main Agent 取得使用者明確確認，記錄授權範圍；未取得前停止該操作。
- 安裝依賴或測試前，先審查套件來源、lockfile、npm lifecycle scripts、測試腳本及外部服務呼叫。
- `npm ci` 與 `npm test` 只能在隔離 Cloud 工作環境執行。由 Main Agent 確認副作用受控、無正式憑證、無正式服務寫入後才執行；不符合條件則回報阻塞。
- 執行前後以 `git status --porcelain` 比對已追蹤檔案；測試產物僅留在核准的隔離範圍，任何差異都要回報，不自行清除使用者變更。
- 回報的命令、輸出與日誌須去除秘密與私人資料；安全問題以最少必要證據描述。
